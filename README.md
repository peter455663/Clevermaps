# Nova Utility Client

Client-side Fabric utility mod for Minecraft Java 26.3.

## Current features
- Lightweight on-screen HUD
- FPS display
- Player block coordinates

## Requirements
- Minecraft Java 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API 0.165.2+26.3 or newer
- Java 25

The mod is client-side and does not grant server permissions or bypass server protections.

## Build
GitHub Actions builds the JAR automatically after a push to `main`.
